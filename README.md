# Tic-Tac-Toe
- Tic-Tac-Toe is a simple 3×3 board game where two players take turns placing X and O. The goal is to get three symbols in a row - either horizontally, vertically, or diagonally.
### This game has two modes-
- Simple Mode – Classic Tic-Tac-Toe rules. Game ends when someone wins or it’s a draw.
- Loop Mode – The game continues even after the board fills. No draw, continuous play.

- Two game modes (Simple & Loop)
- AI-powered opponent
- REST API based architecture
- Real-time win detection
- Cloud deployment

## Tech Stack

- CSS Grid
- Flexbox

### Backend (Server-Side)
- Java 21
- Spring Boot 4.0.2
- Spring Web MVC
- Build Tool
- Maven (with Wrapper)

### Algorithms & Data Structures 
- 2D Array – To represent the 3×3 board
- Minimax – For optimal AI move selection
- Lookahead Search – To evaluate possible future moves
- Linear Scan – For winner detection
- Random Sampling – For non-deterministic AI behavior
- FIFO Queue – For managing game flow logic
- Lookup Table – For optimized state handling

### DevOps

- Render (PaaS deployment).
